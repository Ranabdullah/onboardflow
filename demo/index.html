How OnboardFlow works

  1. Add a client. Choose a name, company and service.
  2. Complete the intake. Goals, scope and assets save as a draft.
  3. Review and submit. Answers become a structured project brief and kickoff tasks.
  4. Track the work. Add dated tasks, assign an owner and mark them complete.
  5. Keep a copy. Export the brief, client report or a restorable workspace backup.

Ready for a private installation?

This public demo has no account or shared cloud records. The full Next.js app uses your own Supabase account for agency login, client links, private uploads and saved projects. Email and AI need your own provider configuration.

Connect your own project

Full setup guide ↗
  1. Get your own copy of OnboardFlow.

    Download or fork the source. Install Node.js 22 or newer and run npm ci in the application folder.

  2. Create a Supabase project in your account.

    Use a new project for your agency. If your account has no available free project slot, use an available project or wait until a slot is free. This demo does not create or upgrade a project.

  3. Configure the private application.

    Copy .env.example to .env.local. Set your project URL, public key, server-only service-role key and application URL on your own machine or host.

    Keep the service-role key on the server. Never paste it into this demo, client forms, screenshots or a public repository.

  4. Prepare the database, Auth and Storage.

    Apply the repository migrations in filename order. Configure Auth site/redirect URLs and verified email delivery. Keep upload and contract buckets private.

  5. Start and verify your private workspace.

    Run npm run build, then npm start. Test sign-in, saved records, private files, backups and each role using separate accounts before inviting your team.

Your demo JSON backup contains browser examples. It is not automatically imported into Supabase and is not a full database backup. Email and AI integrations also require your own provider configuration.
